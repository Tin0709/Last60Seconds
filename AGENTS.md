# Project rules

- Use Godot 4 and GDScript.
- Inspect only files relevant to the current task; avoid full-project scans unless necessary.
- Find the files to modify yourself.
- Make the smallest necessary changes and preserve working behavior.
- Do not refactor unrelated code or overengineer solutions.
- Keep implementations simple for a small 2D indie game.
- Do not commit or push unless explicitly asked.
- After changes, provide only a brief summary and what should be tested.
